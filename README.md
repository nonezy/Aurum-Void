## 📋 О сборке

Космическая сборка на базе **Galacticraft Legacy**, переработанная под тему «золота» (Aurum):
кастомные рецепты, собственный UI и минимализм в модах ради стабильности.

## Состав

- **Основа:** Galacticraft Legacy + More Planets + Galactic Research
- **Технологии:** Mekanism, Extreme Reactors, Refined Storage
- **Интерфейс:** JEI (HEI), The One Probe, Xaero's Minimap / World Map
- **Косметика:** FancyMenu (кастомное меню)
- **Всего модов:** 57

## ✨ Особенности

- 🎨 **Своё меню** — FancyMenu + кастомный GUI-текстурпак (в разработке)
- ⚡ **Оптимизация** — Ksyxis, Clumps, AI Improvements
- 🌌 **Galacticraft + More Planets** с балансными правками

## Установка

### Через Prism Launcher / MultiMC / Modrinth App

1. Скачай последний `.mrpack` из раздела **Releases**.
2. Перетащи файл в окно лаунчера.
3. Лаунчер сам скачает все моды с официальных источников (Modrinth / CurseForge).

Jar-файлы сторонних модов **не хранятся** в репозитории — из уважения к лицензиям авторов.
